# Q11. Application mobile

- **Statut :** décidé
- **Date :** 30 octobre 2026

## Question

Une application mobile native est-elle nécessaire dès la première version ?

## Décision

Application web responsive (PWA). Application native plus tard si nécessaire.

Source : [section 21](../spec/21-decisions.md) ; question 11 de la [section 18](../spec/18-questions-ouvertes.md).
